# DEMO ASSOCIATION

A modern, high-performance web platform for **DEMO ASSOCIATION** — an international business networking community connecting entrepreneurs, executives, and licensed professionals worldwide.

## 🚀 Features

- **Executive Blue Design System**: Crisp typography, high-contrast palette, and responsive layouts.
- **Interactive Sticky Mega Menu**: Dropdowns that stick on click, toggle on second click, close on outside click or `Escape`.
- **Chapter Finder & Modal Workflows**: Interactive locator and membership application flows.
- **Dynamic Event Discovery**: Filterable event calendars and RSVP modals.
- **Responsive Layout**: Mobile-first drawer navigation and desktop viewports.

## 🛠️ Tech Stack

- **React 18** + **Vite**
- **Lucide Icons**
- **Vanilla CSS3** Design System

## 📦 Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start local development server:**
   ```bash
   npm run dev
   ```

3. **Build for production:**
   ```bash
   npm run build
   ```
